The frontier keeps moving

Date
May 5, 2026
Type
Note
I used to worry about AI and work. Now I look for domains where software can help teams handle messy physical systems.

I pursued software engineering because it felt like frontier work. I wanted to build in a field where teams still had to invent the tools as they went.

Many old frontier technologies now run in the background. Wheels, taps, engines, electricity, antibiotics, and the internet reached that point because generations of builders made them reliable.

Biology now pulls my attention. Disease, aging, regeneration, cognition, food systems, diagnostics, and drug discovery still resist clean models. Researchers work across wet labs, patients, manufacturing, policy, and data systems.

Builders can help there. Better tools can shorten experiment loops, make evidence easier to compare, reduce manual review, and help researchers move from messy observations to testable hypotheses.

Computer science gave me a useful habit: break problems down, model systems, test assumptions, and build feedback loops. I can use that habit anywhere complexity blocks useful work.

AI changed the shape of software work. Domain judgment now carries more weight. You still need to understand the workflow, the evidence, the constraints, and the people who will rely on the tool.

I want to work near that edge.
